# 任务文档模板

任务文档写清一项任务要交付的结果和完成判据。规划、执行与审查以它的当前内容判断任务；修改文档后，后续回合按修改后的内容继续。

```markdown
# <任务名称：具体动作和对象>

## 交付结果

<完成后谁能做什么，或系统会出现什么可核实的变化；写明影响结果的必要范围。>

## 验收条件

- <在具体场景下可以观察到的结果，或必须保持的关键约束。>
```

按任务实际情况在末尾添加需要的章节：

```markdown
## 前置结果

- <依赖任务及其必须先交付的结果。>

## 依据

- <相关规格、文件路径或已确认决定，以及与本任务有关的部分。>
```

任务名称、交付结果和验收条件使用自然中文；代码标识符、路径和没有通行中文称呼的固定名称保留原文。一项事实写一次，每项验收条件对应一项可核实的结果。
