# 批任务服务
新建的纯后端产品，供内部脚本调用，没有 UI。当前仓库只有需求，尚无应用代码。
确认范围：提交文本任务取得 task ID，查询该任务的状态与结果；文本处理固定为转大写。任务初态 queued，之后 running，最后 succeeded。用户可以取消 queued 任务，之后它永远不会执行；running 或 succeeded 的任务拒绝取消。本期单进程、内存保存，进程重启丢失任务可以接受。
不包含认证、计费、持久化、通知、前端、任务重试和运行中取消。这些不是当前需求。
产品验收：通过实际接口提交并查询大写结果；通过接口取消 queued 后证明任务未执行；running 与 succeeded 拒绝取消。

旧草稿曾用A1标记提交查询、B1标记取消，仅供对照范围，尚未建立任务。
