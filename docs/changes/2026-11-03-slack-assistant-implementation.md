# [2026-11-03] implement | 本地 Slack 助理

- 依据：用户在审阅[规格](../plans/2026-11-03-slack-assistant-spec.md)、私信与频道免艾特调整及 D1—D6 清单后明确要求“OK，去实现吧”。本地分支为 `codex/slack-assistant`，原始基线 `6b1527e`。
- 结果：增加官方 Slack Socket Mode 接入。机器人私信保持全局连续会话；绑定项目频道直接接收普通消息，新根消息建立独立 Codex 会话并在原讨论串回复。普通查询直接处理，需要工程交付时沿现有 Skills 登记 Codrive 工作。
- 数据：本机私有配置保存连接和项目绑定；Slack 接入记录保存会话关联、输入与发送回执；任务增加成对可选的 `source`、`replyTarget`。来源在调度前与任务一起保存；同来源重试复用原批次和目的地。旧配置和无来源任务保留原行为，允许空项目先登记后绑定。未新增数据库、周期定义或独立 Issue 状态机。
- 交付：报告入口先取得实际消息位置，再交给原生巡检登记工作。任务、项目和里程碑的当前问题使用现有决定身份；失败与完成结果由服务异步通知，发送失败只补送，不重做业务。既有 Skills 补齐客观巡检、合入前预览、后续发布及线上核实责任。不同工作区的回执保持隔离，频道改绑不改变已有工作的回复位置。
- 必要修复：回复按准确回合与消息身份组合，保留没有增量事件的最终答案；恢复时沿用已经登记的最终正文。私信任务支持直接回答或在该问题下开串回答。完整预演发现原有合入确认把自己的仓库占用当作竞争任务，改为复用现有竞争占用检查，保留对其他任务的限制。
