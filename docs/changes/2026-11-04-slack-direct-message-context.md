# Slack 私信上下文、新会话与项目频道展示

用户在日常私信中发现全局上下文不清楚，并要求使用干净目录、开启新会话、在项目资料中查看绑定频道，以及从空频道现场实测创建与绑定。

私信改为使用派生的 `assistant/` 工作目录，每轮获得分开的 Codex 已保存工作空间目录和 Codrive 产品身份；产品身份读取只涉及登记文件，具体项目操作再读取相应规则并使用既有 Skill 命令。目录读取与控制脚本复用同一服务边界。

`/new` 核实授权和当前私信状态后创建新的原生会话，替换已有的当前映射，保留旧原生会话。运行中的消息和外部活跃回合明确拒绝重置。绑定频道的仓库目录与根消息会话保持原有语义。

项目资料独立读取并显示其频道绑定、实际名称与链接；元数据暂不可读时仍保留已保存的频道 ID。频道命令的失败仅返回当前命令，全局运行设置只显示连接生命周期的故障。

以上改动复用现有会话映射、项目登记和频道绑定，没有新增持久字段。私信目录是派生的空工作目录，工作空间目录继续由 Codex 的现有本机记录提供。自动测试覆盖授权、在途切换、目录分离、项目资料与错误归属。

当前 Mac 已真实验证：先清理旧试用频道，再执行 `/new`，由一条自然语言私信自行完成正确项目核对、API 创建私有频道、邀请本人和保存绑定。原生轨迹确认使用了 Control Skill 与创建命令，未调用浏览器；主 Agent 没有代为接通。新频道普通消息无需艾特，机器人在原讨论串回复，实际工作目录是正确的工作空间，开发任务仍为空；项目资料显示真实频道链接。其他项目身份和暂停状态保持不变。
